# 스토리 삽화 연출

`SFStoryWidget.cpp`의 왼쪽 삽화는 배경, 중간, 전경의 세 층으로 구성된다.
페이지를 넘기면 각 층이 시간차를 두고 나타나며, 뒤쪽보다 앞쪽이 더 크게 움직인다.

| 장 | 배경 | 중간 | 전경 |
| --- | --- | --- | --- |
| 1 | 반짝이는 별 | 행성과 궤도 | 에테르와 푸른 입자 |
| 2 | 먼 산과 숲 | 작은 에테르 군락 | 큰 에테르, 나이아가라 |
| 3 | 따뜻한 색의 영토 | 비스트 넥서스 | 비스트 지휘관 대기 애니메이션, 불씨 |
| 4 | 청록색 영토 | 에테리안 넥서스 | 에테리안 지휘관 대기 애니메이션, 에테르 입자 |
| 5 | 공유하는 영토 | 양쪽의 넥서스 | 두 지휘관, 두 색의 나이아가라 |

- 실제 지휘관 메시와 대기 애니메이션은 `SFStoryIllustrationActor`에서 재사용한다.
- 나이아가라와 지휘관은 Scene Capture 전용으로 렌더링하고, 양피지에 UI 머티리얼로 합성한다.
- 캡처는 512×512, 30Hz이며 스토리를 닫거나 로비를 떠날 때 액터를 제거한다.
- 전용 자산은 `/Game/Core/UI/Story`에 있다. 원본 종족 아트와 시작 화면 나이아가라는 수정하지 않는다.
- 전용 자산 재생성: `Scripts/Editor/create_story_illustration.py`.
- 화면·키보드·효과 정리 검증: 로비의 개발 콘솔에서 `SF.Story.Preview LivingArt 1920x1080w`.
  검증 명령은 캡처 후 실행 중인 게임 프로세스를 종료한다.
