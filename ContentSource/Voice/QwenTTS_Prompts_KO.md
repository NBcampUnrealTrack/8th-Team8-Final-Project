# Qwen3-TTS 유닛 보이스 프롬프트

대상: 기존 싸움꾼을 제외한 17종. 견습마법사·비전술사·대마도사로 변경된 설정 반영.
이 문서의 음색과 연기 지시는 제작 제안이며 실제 합성 결과를 들어 보고 조정해야 한다.

## 입력 방법

Qwen3-TTS-12Hz-1.7B-VoiceDesign 기준:
- Language: Korean
- Text to Synthesize / text: 실제 대사 한 문장만 입력
- Voice Description / instruct: 공통 프롬프트 + 유닛 프롬프트 + 선택 또는 이동 지시를 합쳐 입력
- 번호, 유닛 이름, 연기 설명을 대사 칸에 넣지 않는다.

CustomVoice 1.7B는 정해진 speaker에 연기 지시를 적용하는 방식이다. 새로운 캐릭터 음색을 설계할 때는 VoiceDesign을 사용한다. 모든 Qwen 계열 모델이나 UI가 같은 지시 기능을 제공하는 것은 아니다.

## 공통 프롬프트

```text
한국어 표준어로 말하는 판타지 RTS 게임 캐릭터의 짧은 응답이다. 자음과 받침을 또렷하게 발음하고, 문장 끝을 깔끔하게 마무리한다. 자연스러운 성우 연기로 말하며, 한 문장을 한 호흡에 전달한다. 배경음악과 효과음 없이 잔향이 적은 깨끗한 단독 음성으로 녹음한다. 입력된 대사만 말한다.
```

## 선택 대사 추가 지시

```text
플레이어가 자신을 선택해 부른 순간의 응답이다. 자신의 성격이 느껴지도록 자연스럽게 반응한다. 전투를 시작하는 함성보다는 대기 중인 캐릭터의 짧은 대답으로 연기한다.
```

## 이동 대사 추가 지시

```text
이동 명령을 받고 바로 움직이기 시작하는 순간의 응답이다. 선택 대사와 같은 목소리를 유지하고, 약간 더 경쾌하고 단호하게 말한다. 과도하게 흥분하거나 숨이 찬 상태로 연기하지 않는다.
```

광전사는 이동 지시에 “거친 힘과 성급함은 유지한다.”를 추가할 수 있다.
포식자·추적자·혼령술사·암살자는 “경쾌함보다는 조용한 집중을 유지한다.”를 추가할 수 있다.
전쟁야수·거신은 “말속도와 음높이는 유지하고 문장 마무리만 단호하게 한다.”를 추가할 수 있다.

## 캐릭터 목소리 유지

같은 VoiceDesign 설명을 사용해도 합성마다 음색이 달라질 수 있다. 원하는 목소리의 샘플을 먼저 고른 뒤, 공식 VoiceDesign → Base Voice Clone 흐름으로 동일한 참조 음성과 정확한 참조 대본을 재사용하면 캐릭터 일관성을 유지하는 데 도움이 된다.

공식 오픈소스 Base의 Voice Clone은 VoiceDesign의 instruct와 동일한 입력 방식이 아니다. 위 선택·이동 지시는 VoiceDesign 또는 지시를 지원하는 CustomVoice에서 사용하는 프롬프트다.

목소리 확인용 참조 샘플은 해당 유닛의 선택 대사 2~3개를 자연스럽게 이어 읽어 제작할 수 있다. 실제 게임용 음성은 대사 한 개씩 생성하고 별도 파일로 저장한다.

전쟁야수의 “크르르” 같은 발성은 문자 그대로 읽힐 수 있으므로 먼저 테스트한다. 발음이 어색하면 말 대사와 비언어적 발성을 나눠 제작한다.
마법·거신의 잔향과 변조 효과는 원본 음성을 확인한 후 게임 엔진이나 오디오 편집 단계에서 적용하는 것을 권장한다.
