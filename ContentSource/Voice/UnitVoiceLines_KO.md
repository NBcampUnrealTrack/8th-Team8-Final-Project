# 유닛 선택·이동 보이스 대본

프로젝트 DT_Units.csv의 유닛명 기준. 기존 싸움꾼(Brawler)은 제외하고 사냥꾼을 포함한 15종과 양 진영 지휘관 2종을 작성했다. 총 17종 × 선택 5개·이동 5개 = 170개.
캐릭터 성격과 연기 톤은 보이스 제작용 제안이다. 선택 대사는 호출 응답·개성 표현, 이동 대사는 목적지 이동 수락에 맞췄다.

## 비스트

| 번호 | 선택 | 이동 |
|---|---|---|
| 01 | 뭘 잡아드릴까? | 그쪽으로 가지. |
| 02 | 좋은 냄새가 나는데. | 발자국은 남기지 말고. |
| 03 | 눈은 나한테 맡겨. | 먼저 살펴볼게. |
| 04 | 사냥 준비 끝. | 바람을 타고 간다. |
| 05 | 내 차례인가? | 좋아, 자리 옮기자. |

| 03 | 누굴 부숴줄까? | 멈추지 마라! |
| 04 | 하! 이제 내 차례냐? | 좋아, 몸 좀 풀자! |
| 05 | 날 붙잡아둘 순 없지! | 그쪽이냐? 간다! |
